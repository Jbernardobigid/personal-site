Política de Privacidade

Como o Jorge Content Studio trata dados de comentários no Instagram

Este documento descreve o que a integração que publica e administra o Instagram de Jorge Bernardo faz com dados de comentários públicos — em linguagem direta, sem juridiquês.

Última atualização: 22 de junho de 2026
01

O que é o Jorge Content Studio

Jorge Content Studio é o aplicativo Meta que conecta a conta profissional do Instagram de Jorge Bernardo (@jotabernard0) às ferramentas que ele usa para publicar conteúdo e responder a comentários. Não é um produto público: serve exclusivamente para administrar essa conta.

02

Quais dados tratamos

A integração toca dois tipos de dado:

  • O conteúdo do próprio Jorge — fotos, legendas e textos que ele publica, através de um token de acesso da conta dele mesmo.
  • Comentários públicos em posts de Jorge — quando alguém comenta uma palavra-chave específica (por exemplo, "CENSO") em um post, a integração lê o texto do comentário e o nome de usuário e ID de quem comentou, apenas para decidir se deve enviar uma resposta automática.

Não coletamos, lemos ou armazenamos nenhum outro dado de quem comenta — sem acesso a perfil, seguidores, mensagens privadas ou qualquer informação além do texto do comentário público e do identificador necessário para responder a ele.

03

Como usamos esses dados

Quando um comentário contém a palavra-chave configurada, o sistema envia automaticamente uma única mensagem direta privada para quem comentou, contendo um link público (por exemplo, para um relatório ou conteúdo relacionado ao post). Isso é tudo. Não há campanha de marketing, não há coleta de lista de contatos, não há uso posterior desse dado para qualquer outra finalidade.

04

Retenção de dados

Guardamos, por tempo indeterminado em um arquivo de controle interno, apenas o ID do comentário que já recebeu resposta — exclusivamente para evitar enviar a mesma mensagem duas vezes para a mesma pessoa. Não guardamos o texto do comentário, nome de usuário, nem qualquer outro dado pessoal além desse ID técnico.

05

Compartilhamento com terceiros

Nenhum dado é vendido, alugado ou compartilhado com terceiros. A única comunicação de dados que ocorre é com a própria API do Instagram/Meta, necessária para ler o comentário público e enviar a resposta — a mesma infraestrutura que já processa essas informações quando você usa o Instagram normalmente.

06

Segurança

O token de acesso da conta do Instagram é armazenado como segredo de ambiente, nunca em código-fonte público, e usado apenas pelos scripts que rodam essa integração.
